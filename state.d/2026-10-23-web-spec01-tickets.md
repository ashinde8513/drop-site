### Web app spec 01 — multi-seller Tickets card (2026-10-23, Web app specs build lane)
- **Changed:** Event Detail shows every seller for the show (same-show rows from other sources merged with the native fail-closed matcher) in one radiogroup card; one primary "Buy on {Seller}" (`rel="noopener sponsored"`, new tab). Desktop: card tops the sticky right column. Phone: primary in the bottom bar, Sellers icon opens a modal sheet. Old aside buy box, "From $X" organizer price and per-row "Get tickets" buttons removed.
