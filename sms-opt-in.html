SMS verification consent

This hosted document reproduces Drop's in-app consent screen for a one-time phone verification text. The screen is available only to a signed-in user who chooses to add a verified phone number.

  • ✓
    Explicit request

    The user enters their own phone number and taps “Text me a code” before any SMS is sent.

  • ✓
    One verification message

    Drop sends a six-digit verification code that expires after 10 minutes. Message and data rates may apply.

  • ✓
    No recurring or promotional texts

    The number is used for account verification only. Phone-based contact discovery remains off unless the user separately enables it after verification.
